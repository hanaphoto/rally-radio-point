# ラジオポイント通過記録

ラリーのラジオポイント（無線連絡ポスト）で通過車両を記録し、1分ごとに無線で本部へ読み上げるための支援アプリです。

- アプリ: https://hanaphoto.github.io/rally-radio-point/
- 説明書: https://hanaphoto.github.io/rally-radio-point/manual.html

## 使い方

1. 大会名とポイント名を入力する
2. 車両が通過したら、画面テンキーでゼッケン番号（最大4桁）を入力し、「通過を記録」を押す
3. 記録は時計の「分」ごとにまとまって表示される。本部へ読み上げたら、その分の「読み上げ済にする」を押す

## 特徴

- 分ごとの表示: 新しい分が上に並び、いまの分は黄色い枠で表示。読み上げ済にした分は閉じ、その後の記録は次の分の枠に入る
- テキスト生成: 分ごと／全体の2種類。送信用の文章を作ってコピーでき、パネル内で書き換えもできる（例:「ポイント名 10:31台 3台通過／3、12、25」）
- 印刷: A4の表（時刻・ゼッケンと秒・報告済）で出力。実際の通過時刻が枠の分と違う車両は時刻つきで表示
- リセット: 誤タップ防止の2回押し方式（4秒以内にもう一度押すと全消去、大会名・ポイント名は残る）
- 入力の取消: 「クリア」は入力中の数字、「直前を取消」は最後に記録した1件を取り消す

## 注意

- 記録は端末のブラウザ（localStorage）にだけ保存し、外部送信はしません。別のブラウザ・端末には引き継げません
- 記録した時刻の手動修正と、同じゼッケンの重複警告はありません
- 時刻は端末の時計を使うため、運用前に端末の時刻を確認してください
